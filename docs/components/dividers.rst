=========================
Dividers
=========================

Horizontal rules (``<hr>``) and structural section borders implement the
Material Design 3 Divider specification.

.. _divider-tokens-and-specs:

Divider Tokens and Specs
------------------------

The theme defines ``--md-comp-divider-thickness: 1px`` and
``--md-comp-divider-color: var(--md-sys-color-outline-variant)``:

* **Article Horizontal Rules (``.md3-article hr``)**: Rendered as a ``1px``
  hairline using ``background: var(--md-comp-divider-color)`` with ``32px``
  vertical margin.
* **Structural Hairlines**: Used consistently to separate the sticky top app
  bar, primary navigation tabs, navigation drawer, and footer from adjacent
  surfaces.

**MD3 Specification Reference:**
`Components > Divider > Specs > Tokens and specs <https://m3.material.io/components/divider/specs#3ac2a512-7e92-4d92-b729-a1e83536c2c2>`_
